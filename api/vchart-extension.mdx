The `@visactor/vchart-extension` package is an official add-on layer for VChart that ships chart types and components too specialized or heavyweight to bundle by default. It provides full 3D chart variants powered by WebGL (bar3d, pie3d, funnel3d, histogram3d, wordCloud3d, rangeColumn3d), animated narrative charts (rankingBar, storyline, timeline), advanced analysis charts (conversionFunnel, candlestick, pictogram, imageCloud), scatter sequence variants, and a suite of extension components like regression lines, series breaks, bar links, and map labels. Each item is individually tree-shakeable — import only the register function you need and call `VChart.useRegisters([...])`.

## Installation

Install the extension package alongside the core library:

<CodeGroup>
```bash npm
npm install @visactor/vchart @visactor/vchart-extension
```

```bash yarn
yarn add @visactor/vchart @visactor/vchart-extension
```

```bash pnpm
pnpm add @visactor/vchart @visactor/vchart-extension
```
</CodeGroup>

<Note>
`@visactor/vchart-extension` lists `@visactor/vchart` as a peer dependency. Always install both packages together and keep their versions in sync.
</Note>

## The 3D Plugin

Every 3D chart in the extension relies on a shared plugin that wires up WebGL lighting, camera, and the `layout3d` engine. The plugin is automatically called inside each 3D chart's own register function, but you can also invoke it independently if you are composing charts manually.

```ts
import { register3DPlugin } from '@visactor/vchart-extension';

register3DPlugin();
```

Internally `register3DPlugin` registers three VRender primitives:

```ts
// packages/vchart-extension/src/charts/3d/plugin.ts
export const register3DPlugin = () => {
  registerChartPlugin(VChart3dPlugin);
  registerDirectionalLight();
  registerOrthoCamera();
  registerViewTransform3dPlugin();
};
```

Pass `options3d` in the `IInitOption` to control the 3D camera perspective:

```ts
const vchart = new VChart(spec, {
  dom: 'container',
  options3d: { alpha: 0, beta: 0.5, fieldRatio: 0.8 }
});
```

**Complete 3D Bar Chart Example**

The example below registers the bar3d chart, sets up a minimal spec, and mounts it into a `<canvas>` element. The `options3d` parameter is passed via `IInitOption`:

```ts
import VChart from '@visactor/vchart';
import { registerBar3dChart } from '@visactor/vchart-extension';

// Step 1 — register the chart type (calls register3DPlugin internally)
VChart.useRegisters([registerBar3dChart]);

// Step 2 — define the spec
const spec = {
  type: 'bar3d',
  data: [
    {
      id: 'barData',
      values: [
        { month: 'January',  sales: 22 },
        { month: 'February', sales: 13 },
        { month: 'March',    sales: 25 },
        { month: 'April',    sales: 30 },
        { month: 'May',      sales: 19 }
      ]
    }
  ],
  xField: 'month',
  yField: 'sales',
  bar3d: {
    style: { length: 20 }   // depth of the 3D bar in pixels
  },
  axes: [
    { orient: 'bottom', type: 'band' },
    { orient: 'left',   type: 'linear' }
  ]
};

// Step 3 — instantiate with 3D camera options
const vchart = new VChart(spec, {
  dom: 'container',
  options3d: { alpha: 0, beta: 0.45 }
});

vchart.renderAsync();
```

**3D Axis Registers**

When you need explicit axis control in a 3D chart, import the 3D-aware axis variants from the extension:

```ts
import {
  registerCartesianBandAxis3d,
  registerCartesianLinearAxis3d,
  registerCartesianLogAxis3d,
  registerCartesianTimeAxis3d,
  registerCartesianSymlogAxis3d,
  registerAxis3dPlugin
} from '@visactor/vchart-extension';

VChart.useRegisters([
  registerBar3dChart,
  registerAxis3dPlugin,
  registerCartesianBandAxis3d,
  registerCartesianLinearAxis3d
]);
```

**Ranking Bar Example**

```ts
import VChart from '@visactor/vchart';
import { registerRankingBarChart } from '@visactor/vchart-extension';

registerRankingBarChart({ VChart });

const spec = {
  type: 'rankingBar',
  data: [
    {
      id: 'rankingData',
      values: [
        { name: 'Alpha',   value: 420, year: '2020' },
        { name: 'Beta',    value: 380, year: '2020' },
        { name: 'Gamma',   value: 520, year: '2021' },
        { name: 'Alpha',   value: 480, year: '2021' }
      ]
    }
  ],
  xField: 'value',
  yField: 'name',
  timeField: 'year',
  player: { auto: true, interval: 1000 }
};

const vchart = new VChart(spec, { dom: 'container' });
vchart.renderAsync();
```

<Tip>
`registerRankingBarChart` and `registerStorylineChart` accept `{ VChart }` as an optional argument. Pass your own VChart constructor when working in environments where multiple VChart instances coexist.
</Tip>

<Accordion title="Extension Components">

Extension components augment existing charts with additional visual layers. Register them individually alongside the chart types they decorate.

  </Card>
  <Card title="registerRegressionLine" icon="chart-line">
    Draws a regression curve (linear, polynomial, or exponential) over a scatter plot, optionally with a confidence-interval band.
  </Card>
  <Card title="registerExtensionMarkSyncStatePlugin" icon="rotate">
    Plugin that synchronises interaction states (highlight, select, active) across extension marks and their paired series marks.
  </Card>

**Regression Line Example**

```ts
import VChart from '@visactor/vchart';
import { registerRegressionLine } from '@visactor/vchart-extension';

VChart.useRegisters([registerRegressionLine]);

const spec = {
  type: 'scatter',
  data: [{ id: 'scatter', values: [
    { x: 1, y: 2.1 }, { x: 2, y: 3.8 }, { x: 3, y: 5.2 },
    { x: 4, y: 6.9 }, { x: 5, y: 9.1 }
  ]}],
  xField: 'x',
  yField: 'y',
  extensionMark: [
    {
      type: 'component',
      componentType: 'regressionLine',
      dataId: 'scatter',
      style: {
        line: { visible: true, style: { stroke: '#2196F3' } },
        label: { visible: true, text: 'Linear fit' }
      }
    }
  ]
};

const vchart = new VChart(spec, { dom: 'container' });
vchart.renderAsync();
```
