VChart is a cross-platform charting library from the VisActor ecosystem. Built on top of VGrammar and VRender, it delivers expressive, animated, and narrative data visualizations for browsers, Node.js, and mini-program environments—all through a simple declarative JSON spec API.

## Why VChart

VChart goes beyond a standard charting library. Its declarative spec-driven approach makes charts serializable and reproducible, while the underlying visual grammar engine gives you the flexibility to customize every visual element.

## Get Started

<Steps>
  <Step title="Install VChart">
    ```bash
    npm install @visactor/vchart
    ```
  </Step>
  <Step title="Create a chart spec">
    Define your chart using a declarative JSON spec — no complex class hierarchies required.
    ```typescript
    const spec = {
      type: 'bar',
      data: [{ values: [{ x: 'Mon', y: 40 }, { x: 'Tue', y: 65 }] }],
      xField: 'x',
      yField: 'y'
    };
    ```
  </Step>
  <Step title="Render the chart">
    Pass the spec and a container element to instantiate and render.
    ```typescript
    import VChart from '@visactor/vchart';

    const chart = new VChart(spec, { dom: 'chart-container' });
    chart.renderAsync();
    ```
  </Step>
  <Step title="Explore and customize">
    Add themes, interactions, animations, and more through the spec or the VChart instance API.
    See the [Core Concepts](/concepts/spec) guide for a deep dive.
  </Step>
</Steps>
